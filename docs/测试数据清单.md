## 六、验证命令

### 6.1 健康检查

```bash
curl http://localhost:8080/actuator/health
```

### 6.2 系统诊断

```bash
curl -H "X-API-Key: local-dev-key-123" http://localhost:8080/rag/diag
```

### 6.3 完整 RAG 对话（同步）

```bash
curl -H "X-API-Key: local-dev-key-123" \
  "http://localhost:8080/chat?message=高血压患者降压目标是多少？&sessionId=test-001"
```

### 6.4 流式对话（SSE）

```bash
curl -N -H "X-API-Key: local-dev-key-123" -H "Accept: text/event-stream" \
  "http://localhost:8080/chat/stream?message=高血压患者降压目标是多少？&sessionId=stream-001"
```

### 6.5 库存工具

```bash
curl -H "X-API-Key: local-dev-key-123" \
  "http://localhost:8080/lc/tool/inventory?message=查询胃镜活检钳库存"
```

### 6.6 PHI 脱敏

```bash
curl -H "X-API-Key: local-dev-key-123" \
  "http://localhost:8080/lc/tool/phi?message=患者张三，身份证号110101199001011234"
```

### 6.7 引用溯源（按文件名+块号回读原文）

```bash
curl -H "X-API-Key: local-dev-key-123" \
  "http://localhost:8080/rag/chunk?fileName=国家基层高血压防治管理指南2025版.pdf&chunkIndex=19"
```

### 6.8 会话管理

